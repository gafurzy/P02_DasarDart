# Praktikum 2: Dasar – Dasar Pemrograman Dart

Folder ini berisi 24 kode program latihan dari **Modul Praktikum 2: Dasar – Dasar Pemrograman Dart**.

---

| File | Topik / Materi | Catatan / Deskripsi |
|---|---|---|
| `ex1_statement.dart` | Statement | Sintaks dasar statement & deklarasi variabel |
| `ex2_blok.dart` | Blok Program | Blok percabangan `if` dan perulangan `while` |
| `ex3_comment.dart` | Komentar | Komentar 1 baris (`//`), multi-baris (`/* */`), & dokumentasi (`///`) |

| `ex7_variabel1.dart` | Deklarasi Variabel | Deklarasi ringkas multi-variabel dalam satu baris |
| `ex8_variabel2.dart` | Nilai Default Variabel | Pengecekan nilai default variabel (`null`) |
| `ex9_variabel3.dart` | Inisialisasi Variabel | Inisialisasi variabel dan manipulasi nilai aritmatika |
| `ex10_var.dart` | Variabel `var` | Variabel tipe dinamis menggunakan kata kunci `var` tanpa inisialisasi awal |

| `ex17_baca_input.dart` | Membaca Input Keyboard | Input dari terminal via `stdin.readLineSync()` |
| `ex18_konstanta.dart` | Konstanta | Penggunaan kata kunci `final` dan `const` |
| `ex19_tipe_bilangan.dart` | Tipe Data Bilangan | Bilangan heksadesimal, desimal, eksponensial, dan tipe `num` |
| `ex20_tipe_teks.dart` | Tipe Data String | String kutip satu, dua, multi-line triple quote, serta indeks karakter |
| `ex21_tipe_logika.dart` | Tipe Logika Boolean | Tipe data `bool` dengan kondisi if-else modulus |

| `ex23_tipe_map.dart` | Tipe Data Map | Operasi key-value dictionary dan iterasi `forEach()` |
| `ex24_tipe_objek.dart` | Tipe Data Objek / Class | Pembuatan kelas `Person`, konstruktor, method, dan instansiasi |
